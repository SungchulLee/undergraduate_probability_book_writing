# 파산 확률(해석적 풀이)

이 쪽에서는 처음 밑천이 $i = 0, 1, \ldots, N$ 인 모든 경우에 대해 도박꾼의 파산 확률을 해석적으로 구하는 방법을 다룬다. 닫힌 꼴 해를 쓰는 대신, 코드는 선형계 $(I - A)\mathbf{Q} = \mathbf{b}$ 를 곧바로 푼다. 여기서 $A$ 는 흡수벽이 있는 확률보행의 전이행렬이다. 이 방법은 닫힌 꼴 해를 얻을 수 없는 더 복잡한 확률보행으로도 자연스럽게 넓혀진다.

## 배경

도박꾼의 파산 문제에서 참가자는 밑천 $i$ 로 시작해 매 판 \$1을 건다. 참가자는 판마다 확률 $p$ 로 이기고 확률 $q = 1 - p$ 로 진다. 참가자의 돈이 $0$ (파산)이나 $N$ (목표)에 이르면 게임이 끝난다.

### 점화식

밑천 $i$ 에서 시작할 때의 파산 확률을 $Q(i)$ 라 하자. 첫걸음 분석에 따라 다음이 성립한다.

$$
Q(i) = p\,Q(i+1) + q\,Q(i-1), \qquad 1 \le i \le N-1
$$

경계 조건은 $Q(0) = 1$ (파산은 확실하다)과 $Q(N) = 0$ (목표에 이르렀다)이다.

### 행렬로 나타내기

벡터 $\mathbf{Q} = (Q(0), Q(1), \ldots, Q(N))^\top$ 와 성분이 다음과 같은 $(N+1) \times (N+1)$ 전이행렬 $A$ 를 정의하자.

$$
A_{i,i+1} = p, \qquad A_{i,i-1} = q, \qquad 1 \le i \le N-1
$$

흡수상태인 $0$ 과 $N$ 의 전이 성분은 0으로 지운다. 그러면 점화식은 다음과 같이 된다.

$$
(I - A)\,\mathbf{Q} = \mathbf{b}
$$

여기서 $\mathbf{b} = (1, 0, 0, \ldots, 0)^\top$ 가 경계 조건 $Q(0) = 1$ 을 담고 있다.

!!! note "왜 선형계로 푸는가"
    닫힌 꼴 해 $Q(i) = \frac{(q/p)^N - (q/p)^i}{(q/p)^N - 1}$ ($p \ne 1/2$ 일 때)은 우아하지만 $p = 1/2$ 을 따로 다루어야 한다. 행렬로 푸는 방법은 모든 경우를 한결같이 다루고, 상태마다 이길 확률이 다른 경우나 흡수벽이 여럿인 경우, 더 높은 차원의 보행으로도 넓혀진다.

## 코드

```python
"""도박꾼의 파산: 선형계 (I-A)Q = b 를 풀어 파산 확률을 해석적으로 구한다."""
import numpy as np
import matplotlib.pyplot as plt


def compute_ruin_probability(N, p):
    """처음 밑천 i = 0, 1, ..., N 마다 파산 확률 Q[i] 를 구한다."""
    q = 1 - p
    I = np.eye(N + 1)
    A = p * np.eye(N + 1, k=1) + q * np.eye(N + 1, k=-1)
    A[0, 1] = 0
    A[-1, -2] = 0
    b = np.zeros((N + 1, 1))
    b[0, 0] = 1
    Q = np.linalg.solve(I - A, b).reshape(N + 1)
    return Q


def main():
    N = 100  # 목표
    p = 0.49

    Q = compute_ruin_probability(N, p)

    plt.figure(figsize=(8, 5))
    plt.plot(Q, linewidth=2)
    plt.title(f"Probability of Ruin (p = {p}, goal = {N})")
    plt.xlabel("Initial Capital")
    plt.ylabel("Ruin Probability")
    plt.grid(True, alpha=0.3)
    plt.tight_layout()
    plt.savefig("ruin_probability.png", dpi=150, bbox_inches="tight")
    plt.show()

    idx = np.where(Q <= 0.5)[0][0]
    print(f"Minimum initial capital with ruin probability <= 0.5: {idx}")


if __name__ == "__main__":
    main()
```

## 실행 결과

이 코드는 그림 하나와 한 줄짜리 글자 출력을 내놓는다.

**그림:** $p = 0.49$ 이고 $N = 100$ 일 때 처음 밑천 $i$ 에 대한 $Q(i)$ 의 곡선이다. 파산 확률은 $i = 0$ 에서 $1$ 이고 밑천이 늘어남에 따라 줄어들어 $i = N = 100$ 에서 $0$ 이 된다. 곡선은 오목하고 $i = 0$ 근처에서 가파르게 떨어지는데, 이는 $p < 1/2$ 일 때 밑천이 적은 채로 시작하는 것이 얼마나 불리한지를 보여 준다.

**글자 출력:**

```
Minimum initial capital with ruin probability <= 0.5: 85
```

!!! tip "이 경계를 어떻게 읽을 것인가"
    $p = 0.49$ (하우스가 조금 유리하다)이고 목표가 $N = 100$ 일 때, 도박꾼이 빈털터리가 되기 전에 \$100에 이를 가능성이 반이라도 넘으려면 처음 밑천이 적어도 \$85는 있어야 한다. 작은 우위가 여러 판에 걸쳐 어떻게 쌓이는지를 잘 보여 준다.

## 뜻풀이

해석적인 풀이는 도박꾼의 파산이 지닌 중요한 성질 몇 가지를 드러낸다.

1. **치우침에 민감하다.** $p = 0.5$ 에서 조금만 벗어나도 효과가 극적이다. $p = 0.49$ 이고 $N = 100$ 일 때 $i = 50$ (목표의 절반)에서의 파산 확률은 공정한 게임의 값 $0.50$ 이 아니라 약 $0.88$ 이다.

2. **지수적으로 달라진다.** 닫힌 꼴 해를 보면 $Q(i)$ 가 $(q/p)^i$ 에 달려 있다. $q/p > 1$ (불리한 게임)이면 이 비가 지수적으로 커지므로 $i$ 가 $N$ 에 아주 가깝지 않은 한 파산은 거의 확실해진다.

3. **현실에서의 뜻.** 카지노에서 하우스가 $1\%$ 만 유리해도, 충분히 오래 노는 도박꾼은 거의 확실하게 파산한다. 살아남을 확률을 제대로 확보하는 유일한 길은 목표에 아주 가까운 데서 시작하는 것뿐이다.

행렬을 쓰는 방법은 닫힌 꼴 공식과 기계 정밀도까지 일치하므로 쓸모 있는 수치 검산이 된다.

## 연습문제

**연습문제 1.** 닫힌 꼴 공식을 써서 $p = 0.49$ 이고 $N = 100$ 일 때의 파산 확률 $Q(50)$ 을 구하여라. 코드로 얻은 수치 해와 견주어 보아라.

??? success "연습문제 1 풀이"
    $p \ne 1/2$ 일 때의 닫힌 꼴 공식은 다음과 같다.

    $$
    Q(i) = \frac{(q/p)^N - (q/p)^i}{(q/p)^N - 1}
    $$

    $p = 0.49$, $q = 0.51$ 이므로 $r = q/p = 51/49 \approx 1.04082$ 이다.

    $$
    Q(50) = \frac{r^{100} - r^{50}}{r^{100} - 1}
    $$

    계산하면 $r^{50} \approx 7.355$ 이고 $r^{100} \approx 54.10$ 이다. 그러므로 다음을 얻는다.

    $$
    Q(50) = \frac{54.10 - 7.355}{54.10 - 1} = \frac{46.74}{53.10} \approx 0.880
    $$

    이 값은 `compute_ruin_probability(100, 0.49)[50]` 의 수치 결과와 기계 정밀도까지 일치한다. $\square$

**연습문제 2.** $N = 100$ 으로 두고 $p = 0.45, 0.49, 0.50, 0.51$ 에 대한 $Q(i)$ 를 한 그림에 함께 그리도록 코드를 고쳐라. $p$ 가 달라짐에 따라 곡선이 어떻게 바뀌는지 서술하여라.

??? success "연습문제 2 풀이"
    ```python
    import numpy as np
    import matplotlib.pyplot as plt

    def compute_ruin_probability(N, p):
        q = 1 - p
        I = np.eye(N + 1)
        A = p * np.eye(N + 1, k=1) + q * np.eye(N + 1, k=-1)
        A[0, 1] = 0
        A[-1, -2] = 0
        b = np.zeros((N + 1, 1))
        b[0, 0] = 1
        return np.linalg.solve(I - A, b).reshape(N + 1)

    if __name__ == "__main__":
        N = 100
        plt.figure(figsize=(8, 5))
        for p in [0.45, 0.49, 0.50, 0.51]:
            Q = compute_ruin_probability(N, p)
            plt.plot(Q, label=f"p = {p}", linewidth=2)
        plt.xlabel("Initial Capital")
        plt.ylabel("Ruin Probability")
        plt.legend()
        plt.grid(True, alpha=0.3)
        plt.tight_layout()
        plt.show()
    ```

    - **$p = 0.45$:** 곡선이 대부분의 $i$ 에서 $1$ 에 붙어 있다가 $N = 100$ 아주 가까이에서야 $0$ 으로 떨어진다. 도박꾼이 목표 근처에서 시작하지 않는 한 파산은 거의 확실하다.
    - **$p = 0.49$:** 여전히 파산 확률이 높지만 더 완만하게 떨어진다.
    - **$p = 0.50$:** 곡선이 직선이다. $Q(i) = 1 - i/N$ 으로 대칭 확률보행을 그대로 보여 준다.
    - **$p = 0.51$:** 곡선이 빠르게 떨어져 웬만한 $i$ 에서는 $0$ 에 가깝게 붙어 있다. 이제 도박꾼 쪽이 유리하므로 처음 밑천이 아주 적지 않은 한 파산할 일이 드물다.

    $\square$

**연습문제 3.** $p = 1/2$ 일 때 점화식을 곧바로 풀어 파산 확률이 $Q(i) = 1 - i/N$ 임을 증명하여라.

??? success "연습문제 3 풀이"
    $p = q = 1/2$ 이면 점화식은 다음과 같다.

    $$
    Q(i) = \frac{1}{2}\,Q(i+1) + \frac{1}{2}\,Q(i-1)
    $$

    옮겨 쓰면 $Q(i+1) - Q(i) = Q(i) - Q(i-1)$ 이다. 곧 계차가 일정하다는 뜻이다. $d = Q(1) - Q(0)$ 이라 하자. 그러면 다음과 같다.

    $$
    Q(i) = Q(0) + i\,d = 1 + i\,d
    $$

    $Q(N) = 0$ 을 적용하면 $0 = 1 + N\,d$ 이므로 $d = -1/N$ 이다. 그러므로 다음을 얻는다.

    $$
    Q(i) = 1 - \frac{i}{N}
    $$

    이는 $Q(0) = 1$ 과 $Q(N) = 0$ 사이를 잇는 일차함수이다. $\square$

**연습문제 4.** 코드에 나오는 전이행렬 $A$ 는 삼중대각행렬이다. `A[0, 1]` 과 `A[-1, -2]` 를 0으로 만드는 것이 왜 흡수 경계 조건을 제대로 담아내는지 설명하여라.

??? success "연습문제 4 풀이"
    손대지 않으면 $A$ 의 $0$ 행에는 $A_{0,1} = p$ 가 들어 있어 상태 $0$ 에서 상태 $1$ 로 옮겨 가는 것을 나타내게 된다. 그런데 상태 $0$ 은 흡수상태이므로(한 번 파산하면 계속 파산한 채로 남는다) 상태 $0$ 에서 빠져나가는 전이가 있어서는 안 된다. $A_{0,1} = 0$ 으로 두면 $0$ 행이 모두 0이 되어 $Q(0)$ 에 대한 식이 다음과 같이 된다.

    $$
    (I - A)_{0,:}\,\mathbf{Q} = Q(0) = b_0 = 1
    $$

    마찬가지로 $A$ 의 $N$ 행에는 $A_{N,N-1} = q$ 가 들어 있게 된다. 상태 $N$ 도 흡수상태이므로(목표에 이르렀다) $A_{N,N-1} = 0$ 으로 두면 $N$ 행이 모두 0이 되어 다음을 얻는다.

    $$
    (I - A)_{N,:}\,\mathbf{Q} = Q(N) = b_N = 0
    $$

    안쪽 행 $1 \le i \le N-1$ 은 삼중대각 구조를 그대로 지녀 $Q(i) = p\,Q(i+1) + q\,Q(i-1)$ 을 담아낸다. $\square$

**연습문제 5.** 이길 확률이 현재 밑천에 따라 달라져 $0 < i < N$ 에서 $p_i = 0.5 + 0.01\,i/N$ 이라고 하자. 상태에 따라 확률이 달라지는 경우를 다루도록 코드를 고치고 $N = 100$ 에 대한 파산 확률 곡선을 그려라.

??? success "연습문제 5 풀이"
    ```python
    import numpy as np
    import matplotlib.pyplot as plt

    def compute_ruin_variable_p(N):
        I_mat = np.eye(N + 1)
        A = np.zeros((N + 1, N + 1))
        for i in range(1, N):
            p_i = 0.5 + 0.01 * i / N
            q_i = 1 - p_i
            A[i, i + 1] = p_i
            A[i, i - 1] = q_i
        b = np.zeros((N + 1, 1))
        b[0, 0] = 1
        Q = np.linalg.solve(I_mat - A, b).reshape(N + 1)
        return Q

    if __name__ == "__main__":
        N = 100
        Q = compute_ruin_variable_p(N)
        plt.figure(figsize=(8, 5))
        plt.plot(Q, linewidth=2, label="Variable p(i)")
        plt.plot(1 - np.arange(N + 1) / N, "--", alpha=0.5, label="Fair game (p=0.5)")
        plt.xlabel("Initial Capital")
        plt.ylabel("Ruin Probability")
        plt.legend()
        plt.grid(True, alpha=0.3)
        plt.tight_layout()
        plt.show()
    ```

    모든 $i > 0$ 에서 $p_i > 0.5$ 이므로 도박꾼은 조금 유리하고 그 우위는 밑천이 늘수록 커진다. 파산 확률 곡선은 공정한 게임의 직선 $Q(i) = 1 - i/N$ 아래로 내려가며, 우위가 가장 큰 큰 $i$ 쪽에서 특히 그렇다. 전이확률이 일정하지 않을 때에도 행렬로 푸는 방법이 얼마나 유연한지를 보여 준다. $\square$

**연습문제 6.** 코드에 나오는 행렬 $I - A$ 가 모든 $0 < p < 1$ 에 대해 엄격 대각우세임을 보이고, 따라서 비특이임(곧 선형계가 언제나 유일한 해를 가짐)을 결론지어라.

??? success "연습문제 6 풀이"
    행렬 $M$ 이 모든 행 $i$ 에 대해 $|M_{ii}| > \sum_{j \ne i} |M_{ij}|$ 를 만족하면 **엄격 대각우세**라고 한다.

    $I - A$ 에서는 모든 $i$ 에 대해 대각성분이 $(I - A)_{ii} = 1$ 이다. 행마다 살펴보자.

    - **$0$ 행:** $A$ 의 $0$ 행에 있는 비대각성분은 모두 $0$ 이다(흡수상태). 그러므로 $|1| > 0$ 으로 만족한다.
    - **$N$ 행:** 같은 논리로 $|1| > 0$ 이므로 만족한다.
    - **$1 \le i \le N-1$ 행:** $I - A$ 의 비대각성분은 $(i, i+1)$ 자리에 $-p$, $(i, i-1)$ 자리에 $-q$ 이다. 절댓값의 합은 $p + q = 1$ 이다. 그러면 $|1| = 1$ 이 되어 $1$ 보다 *엄격히* 크지는 않다.

    안쪽 행에서는 등호가 되므로 $I - A$ 는 *약한* 대각우세일 뿐이다. 그러나 $I - A$ 는 **기약 대각우세** 행렬이다. 경계 행은 엄격 우세이고, 안쪽 상태들은 삼중대각 구조를 통해 경계와 이어져 있기 때문이다. 대각우세 정리의 강화된 형태(타우스키 정리)에 따라 $I - A$ 는 비특이이다.

    다른 방법으로는 이렇게 볼 수도 있다. $A$ 는 과도상태(행 $1, \ldots, N-1$)에 대해 행합이 $1$ 인 아확률행렬을 나타낸다. 확률보행이 확률 $1$ 로 흡수되므로 과도상태 블록의 스펙트럼 반지름은 $\rho(A_T) < 1$ 을 만족한다. 그러므로 $I - A_T$ 가 비특이이고, 따라서 전체 계 $I - A$ 도 비특이이다. $\square$
