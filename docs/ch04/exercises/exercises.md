# Chapter 4 Exercises

!!! warning "Exercise page"
    This page collects practice problems for Chapter 4 and does not follow the five-section structure used by concept pages.

Exercises on random variables, PMFs, CDFs, PDFs, and functions of random variables.

## Section 4.1 — Random Variables

**Exercise 4.1.** Explain in your own words why $P(X = a) = 0$ for every value $a$ when $X$ is a continuous random variable, even though $X$ must take some value.

**Exercise 4.2.** Flip a fair coin four times. Let $X$ = number of heads in the first two flips and $Y$ = number of heads in all four flips. List all 16 outcomes and compute the PMFs of $X$ and $Y$.

## Section 4.2 — PMF

**Exercise 4.3.** Let $X$ be the number of heads in 3 flips of a fair coin. Write down the PMF of $X$ and verify it sums to 1.

**Exercise 4.4.** A random variable $X$ has PMF $P(X = k) = c \cdot k$ for $k = 1, 2, 3, 4, 5$. Find the constant $c$ and compute $P(X \ge 3)$.

**Exercise 4.5.** Determine whether each of the following is a valid PMF. If not, explain why.

(a) $p(k) = 1/k$ for $k = 1, 2, 3, \ldots$

(b) $p(k) = (1/2)^k$ for $k = 1, 2, 3, \ldots$

(c) $p(k) = (k-3)/4$ for $k = 1, 2, 3, 4, 5$

## Section 4.3 — CDF

**Exercise 4.6.** Given the PMF from Exercise 4.3, write the CDF $F(x)$ as a piecewise function and sketch it.

**Exercise 4.7.** A random variable $X$ has the CDF with jumps at $x = 5, 10, 20, 25$ of sizes $0.2, 0.3, 0.1, 0.4$. Determine $P(X = 10)$, $P(X \ge 20)$, and $P(5 < X \le 20)$.

**Exercise 4.8.** A continuous random variable has PDF $f(x) = 3x^2$ for $0 \le x \le 1$. Find the CDF and compute $P(0.5 \le X \le 0.8)$.

## Section 4.4 — PDF

**Exercise 4.9.** Verify that $f(x) = 6x(1-x)$ for $0 \le x \le 1$ is a valid PDF. Find the CDF, and compute $P(X > 0.5)$.

**Exercise 4.10.** A continuous random variable has CDF $F(x) = 1 - e^{-2x}$ for $x \ge 0$. Find the PDF and compute $P(1 < X < 3)$.

## Section 4.5 — Functions of Random Variables

**Exercise 4.11.** If $X \sim \text{Bern}(0.3)$, find the PMF of $Y = 5X + 2$.

**Exercise 4.12.** Let $X$ take values $\{-2, -1, 0, 1, 2\}$ each with probability $1/5$. Find the PMF of $Y = |X|$ and the PMF of $Z = X^2$.

**Exercise 4.13.** Let $X \sim \text{Uniform}(0, 1)$. Use the CDF method to find the PDF of $Y = X^3$.

**Exercise 4.14.** Let $X \sim \text{Exp}(\lambda)$. Use the change-of-variables formula to find the PDF of $Y = \sqrt{X}$.
