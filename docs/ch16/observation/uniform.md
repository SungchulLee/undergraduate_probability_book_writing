# 균등확률변수의 합

이 쪽에서는 독립이고 같은 분포를 따르는 연속균등확률변수의 합이 더하는 개수가 늘어남에 따라 정규분포로 수렴함을 보인다. 균등확률변수 하나의 밀도함수는 완전히 평평한데도, 그 합은 차츰 낯익은 종 모양을 갖추어 간다.

## 배경

**연속균등**확률변수 $X \sim U(a, b)$ 는 $[a, b]$ 위에서 상수인 밀도 $f(x) = 1/(b-a)$ 를 가진다. 대칭인 경우 $X \sim U(-1/2, 1/2)$ 의 평균과 분산은 다음과 같다.

$$
E[X] = 0, \qquad \text{Var}(X) = \frac{1}{12}.
$$

독립인 복사본 $n$ 개의 합은 다음과 같고

$$
S_n = X_1 + X_2 + \cdots + X_n,
$$

그 평균과 분산은 다음과 같다.

$$
E[S_n] = 0, \qquad \text{Var}(S_n) = \frac{n}{12}.
$$

$S_n$ 의 밀도함수는 균등분포의 밀도함수를 자기 자신과 $n$ 번 합성곱한 것이다. 이를 **어윈–홀 분포**라 한다(받침이 $[0, n]$ 일 때의 이름이며, 여기에서 다루는 중심을 옮긴 형태는 받침이 $[-n/2, n/2]$ 이다). 벌써 $n = 2$ 에서 합성곱은 삼각형 모양의 밀도를 내놓고, 합성곱을 한 번 더 할 때마다 밀도함수는 가우스 모양 쪽으로 한층 더 매끄러워진다.

## 코드

```python
"""i.i.d. U(-0.5, 0.5) 확률변수의 합이 정규분포로 다가가는 모습."""
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

np.random.seed(42)
n_sim = 10000

fig, axes = plt.subplots(2, 3, figsize=(14, 8))
for idx, n in enumerate([2, 3, 5, 10, 30, 100]):
    ax = axes.flatten()[idx]
    S = np.sum(np.random.uniform(-0.5, 0.5, (n, n_sim)), axis=0)
    ax.hist(S, bins=100, density=True, alpha=0.7, color='steelblue')
    mu, sigma = 0, np.sqrt(n/12)
    x = np.linspace(mu - 4*sigma, mu + 4*sigma, 200)
    ax.plot(x, stats.norm.pdf(x, mu, sigma), 'r-', lw=2)
    ax.set_title(f'n = {n}')
    ax.grid(True, alpha=0.3)

plt.suptitle('Sum of U(-1/2, 1/2) -> Normal', fontsize=14, fontweight='bold')
plt.tight_layout()
plt.savefig('uniform_clt.png', dpi=150, bbox_inches='tight')
plt.show()
```

## 실행 결과

이 스크립트는 $n = 2, 3, 5, 10, 30, 100$ 에 대한 히스토그램을 $2 \times 3$ 격자로 그린다. 각 히스토그램은 10,000번의 모의실험에서 얻은 $S_n$ 의 경험적 분포를 보여 주고, 그 위에 대응하는 정규분포 밀도함수 $N(0, n/12)$ 를 빨간 곡선으로 겹쳐 놓는다.

- $n = 2$ 에서는 히스토그램이 삼각형을 이룬다(균등분포 밀도함수 두 개의 합성곱이다).
- $n = 3$ 에서는 밀도함수가 구간마다 이차식이고 평평한 부분이 눈에 띈다.
- $n = 5$ 쯤 되면 모양이 이미 종 모양에 가깝다.
- $n = 30$ 과 $n = 100$ 에서는 히스토그램과 정규분포 곡선이 사실상 같다.

## 뜻풀이

균등분포는 중심극한정리를 보여 주는 출발점으로 삼기에 더없이 좋다. 개개의 $X_i$ 가 가진 밀도함수는 종 모양과는 조금도 닮지 않은, 완전히 평평한 모양이기 때문이다. 눈여겨볼 점은 다음과 같다.

1. **빠른 수렴.** 균등분포는 대칭이고 꼬리가 가볍기(받침이 유계이기) 때문에 정규분포로의 수렴이 빠르다. $n = 5$ 만 되어도 근사가 꽤 좋다.
2. **합성곱을 정확히 안다.** 균등확률변수 $n$ 개의 합은 구간마다 다항식인 닫힌 꼴의 밀도함수(어윈–홀 밀도함수)를 가지므로, 이 다항식들이 가우스 곡선으로 다가감을 해석적으로 확인할 수 있다.
3. **대칭성이 도와준다.** $U(-1/2, 1/2)$ 가 $0$ 을 중심으로 대칭이므로 모든 $n$ 에 대하여 $S_n$ 이 대칭이고, $n$ 이 커지며 "바로잡아야" 할 왜도가 아예 없다. 지수분포처럼 한쪽으로 치우친 분포보다 수렴이 빠른 까닭이 여기에 있다.

## 연습문제

**연습문제 1.**
$X_i \sim U(-1/2, 1/2)$ 일 때 합성곱 적분을 직접 계산하여 $S_2 = X_1 + X_2$ 의 밀도함수를 구하여라. 그것이 삼각형 모양의 밀도함수임을 확인하여라.

??? success "연습문제 1 풀이"
    각 $X_i$ 의 밀도함수는 $x \in [-1/2, 1/2]$ 에서 $f(x) = 1$ 이고 그 밖에서는 $0$ 이다. 합성곱은 다음과 같다.

    $$
    f_{S_2}(s) = \int_{-\infty}^{\infty} f(x) f(s - x) \, dx = \int_{-1/2}^{1/2} \mathbf{1}_{[-1/2, 1/2]}(s - x) \, dx.
    $$

    피적분함수가 $0$ 이 아니려면 $-1/2 \leq x \leq 1/2$ 이면서 동시에 $-1/2 \leq s - x \leq 1/2$, 곧 $s - 1/2 \leq x \leq s + 1/2$ 이어야 한다. 따라서 적분 구간은 $\max(-1/2, s - 1/2) \leq x \leq \min(1/2, s + 1/2)$ 이다.

    $-1 \leq s \leq 0$ 일 때: $f_{S_2}(s) = 1/2 - (s - 1/2) + 1 - 1 = 1 + s$.

    $0 \leq s \leq 1$ 일 때: $f_{S_2}(s) = s + 1/2 - (-1/2) + 1 - 1 = 1 - s$.

    합치면 $f_{S_2}(s) = \max(0, 1 - |s|)$ 이고, 이것은 $[-1, 1]$ 위의 삼각형 모양 밀도함수이다.

---

**연습문제 2.**
$n \to \infty$ 일 때 $S_n$ 의 첨도가 정규분포의 첨도($\kappa = 3$)로 다가감을 보여라.

??? success "연습문제 2 풀이"
    $U(-1/2, 1/2)$ 확률변수 하나의 첨도는 $\kappa_X = 9/5$ 이다(4차 적률이 $1/80$ 이고 분산이 $1/12$ 이므로 $\kappa_X = (1/80)/(1/12)^2 = 9/5$ 이다). 독립인 확률변수들에 대하여 합의 초과첨도는 다음을 만족한다.

    $$
    \kappa_{\text{excess}}(S_n) = \frac{\kappa_{\text{excess}}(X)}{n} = \frac{9/5 - 3}{n} = \frac{-6/5}{n} = \frac{-6}{5n}.
    $$

    $n \to \infty$ 일 때 초과첨도가 $0$ 으로 가므로 첨도는 $\kappa(S_n) \to 3$ 이 되고, 이것이 바로 정규분포의 값이다.

---

**연습문제 3.**
$U(-1/2, 1/2)$ 대신 $U(0, 1)$ 을 쓰도록 모의실험을 고쳐라. $S_n$ 의 평균과 분산은 어떻게 달라지는가? 정규분포로의 수렴은 달라지는가?

??? success "연습문제 3 풀이"
    $X_i \sim U(0, 1)$ 이면 $E[X_i] = 1/2$ 이고 $\text{Var}(X_i) = 1/12$ 이다. 따라서 $E[S_n] = n/2$ 이고 $\text{Var}(S_n) = n/12$ 이다. 평균은 $0$ 에서 $n/2$ 으로 옮겨 가지만 분산은 그대로이다. 정규분포로의 수렴 속도도 같다. 옮겨 놓은 양이 상수이므로 표준화한 변수 $(S_n - n/2)/\sqrt{n/12}$ 의 분포가 이전과 같기 때문이다. 코드에서는 `np.random.uniform(-0.5, 0.5, ...)` 를 `np.random.uniform(0, 1, ...)` 로 바꾸고 $\mu$ 를 `n * 0.5` 로 고치면 된다.

---

**연습문제 4.**
어윈–홀 분포는 i.i.d. $U(0,1)$ 확률변수 $n$ 개의 합의 정확한 밀도함수를 준다. 일반적인 $n$ 에 대하여 그 식을 적고, $n = 2$ 일 때 연습문제 1의 답과 일치함을 확인하여라.

??? success "연습문제 4 풀이"
    $X_i \sim U(0,1)$ 일 때 $S_n = X_1 + \cdots + X_n$ 의 밀도함수는 어윈–홀 밀도함수이다.

    $$
    f_{S_n}(s) = \frac{1}{(n-1)!} \sum_{k=0}^{\lfloor s \rfloor} (-1)^k \binom{n}{k} (s-k)^{n-1}, \qquad 0 \leq s \leq n.
    $$

    $n = 2$ 인 경우를 보자. $0 \leq s \leq 1$ 이면 $k = 0$ 항만 남아 $f_{S_2}(s) = s$ 이다. $1 < s \leq 2$ 이면 $k = 0$ 과 $k = 1$ 이 모두 남아 $f_{S_2}(s) = s - 2(s-1) = 2 - s$ 이다. 이것은 $[0, 2]$ 위의 삼각형 모양 밀도함수이며, $s \mapsto s + 1$ 로 옮기면 연습문제 1의 답과 일치한다.

---

**연습문제 5.**
모의실험에서 $S_{12} - 6$ 을 $N(0, 1)$ 의 손쉬운 근사로 쓰는 일이 있다. 이 값의 평균과 분산, 받침은 무엇인가? 어째서 근사일 뿐인가?

??? success "연습문제 5 풀이"
    $X_i \sim U(0, 1)$ 에 대하여 $S_{12} = X_1 + \cdots + X_{12}$ 로 놓자. 그러면 $E[S_{12}] = 6$ 이고 $\text{Var}(S_{12}) = 12/12 = 1$ 이다. 따라서 $Z = S_{12} - 6$ 은 평균이 $0$, 분산이 $1$ 로 $N(0, 1)$ 의 처음 두 적률과 일치한다.

    그러나 $Z$ 는 다음과 같은 까닭으로 근사일 뿐이다.

    - 받침이 $[-6, 6]$ 인 데 견주어 $N(0, 1)$ 의 받침은 $(-\infty, \infty)$ 이다.
    - $\pm 6$ 을 넘어서는 확률이 $0$ 이므로 극단적인 꼬리값을 만들어 낼 수 없다.
    - 밀도함수가 가우스 함수가 아니라 구간마다 11차인 다항식이다.
    - 초과첨도가 $-6/(5 \cdot 12) = -0.1$ 로, 정규분포보다 약간 납작하다.

    이런 한계가 있는데도 실용적인 목적에서는 근사가 놀랄 만큼 잘 맞아서, 박스–뮐러 방법 같은 효율적인 정규난수 생성기가 표준이 되기 전에는 역사적으로 널리 쓰였다.
